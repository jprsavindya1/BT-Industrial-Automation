# BT Industrial Automation

## Technology Stack

This project is built using modern web development technologies for both the frontend and backend.

### Backend

The backend of this application is powered by:

* **[PHP](https://www.php.net/) (v8.2+)**: The primary server-side programming language.
* **[Laravel](https://laravel.com/) (v12.0)**: A powerful and elegant PHP web application framework used for routing, database interaction, authentication, and API development.

### Frontend

The frontend is designed to be fast and responsive, utilizing:

* **JavaScript**: The core scripting language for interactive frontend features.
* **[Tailwind CSS](https://tailwindcss.com/) (v4.0)**: A utility-first CSS framework for rapid and modern UI styling.
* **[Vite](https://vitejs.dev/) (v7.0)**: A lightning-fast frontend build tool and asset bundler.

### Database

* **SQLite** (Default): Currently configured to use SQLite for data storage, though Laravel supports seamless migration to MySQL, PostgreSQL, etc.

### Package Management

* **Composer**: Used for managing PHP dependencies.
* **npm**: Used for managing JavaScript/Node.js dependencies.
